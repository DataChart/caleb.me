    Retrieval-augmented generation

    Webscraped RAG chatbot

    Read the code walkthrough →
    • ModelA local chatbot that answers questions about a utility co-op using only text from its own website, and cites the pages it used.
    • Training processNo weights were trained. I scraped 247 web pages and 73 PDFs, split them into 3,329 overlapping 150-word chunks, and embedded them into ChromaDB. Each question retrieves the 5 nearest chunks as context.
    • ToolsPython, BeautifulSoup, PyMuPDF, sentence-transformers (all-MiniLM-L6-v2), ChromaDB, LM Studio
    • Base modelMistral, running locally in LM Studio

    Python code commenter

    Read the write-up →
    • ModelReads uncommented Python function definitions and writes a one-line docstring for each one.
    • Training processFine-tuned on 10,000 Python functions paired with their docstrings. Our team of four rated it 1.43 out of 2 on more than 90 functions (my own ratings averaged 1.56).
