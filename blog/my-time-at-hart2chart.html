My time at Hart2Chart

From July 2025 to April 2026 I ran Hart2Chart, my own freelance web development and consulting practice. Clients found me through Fiverr, TaskRabbit, LinkedIn and direct referrals, and I built custom HTML, CSS and JavaScript for them, specializing in data-focused websites, professional portfolios, interactive dashboards and real-time monitoring interfaces.

How I worked

I ran projects on an accelerated one-week development cycle, with customer meetings twice a week to gather requirements, review progress, fold in feedback and validate the final deliverable. I handled the whole client lifecycle myself: requirements, UI design, development, testing, feedback, revisions, payments and final delivery. I kept a 5-star customer rating throughout.

What I built

  • 2 professional resume websites and 3 project portfolio websites.
  • 4 interactive financial dashboards that turned financial data into browser-based reports.
  • 2 low-latency, real-time data monitoring dashboards with sub-second refresh and rendering.

A framework of my own

Building the same pieces for different clients pushed me to make them reusable. I created a source-controlled, open-source HTML dashboard framework with templates, selectors, buttons, charts, UI components and tutorials for building interactive web reports. I later expanded and rebranded it as AtlasHTMLCharts on GitHub.
