Reinforcement Learning

Teaching an agent to play Minesweeper

Source on GitHub

github.com/DataChart/ReinforcementLearningMinesweeper

For Reinforcement Learning (STAT407, Spring 2025), I built an agent that plays Minesweeper. It's a perfect RL playground. The rules are tiny, the board is a grid, and every click is a decision under uncertainty: reveal a safe square and you learn something, guess wrong and the episode is over.

Building the environment

I wrote a custom environment with the Gymnasium (OpenAI Gym) API. The board is 9×9 with 20 mines. The agent sees the board as revealed so far, as a 9×9 grid of values between −1 and 1, and its action is simply which tile to click. Episodes are capped at 200 steps so a confused agent can't loop forever.

The rewards do most of the teaching:

  • Win: +50
  • Lose (hit a mine): −10
  • Progress (reveal new safe tiles): +1
  • Guess (click with no information to go on): −0.3
  • No progress (click something already revealed): −0.1

I optimized them for two things at once: win rate, and solving efficiency, meaning clearing the board without wasted moves. The last version of the notebook also adds a fixed-mine mode, which places the mines in the same spots every game so you can check that the agent is really learning before you make the problem harder.

Three ways to learn

The core agent uses REINFORCE, a Monte Carlo policy gradient method. A small policy network (flatten, two 128-unit layers with ReLU, and a softmax over every tile) outputs a probability for each click. After each game, the returns are discounted (γ = 0.99) and normalized, and the network is nudged toward the clicks that led to good outcomes, using Adam with a 0.001 learning rate. There's no separate value network: it learns directly from how each game turned out.

I compared it against value-based methods, a Deep Q-Network (DQN) and SARSA, both with ε-greedy exploration that starts fully random and decays toward 1%. The question underneath is exploration versus exploitation: how often should the agent try something new to learn, and how often should it cash in on what it already knows? In Minesweeper, too much exploration means clicking mines, and too little means never finding the patterns that make the game solvable.

Results

The deep reinforcement learning strategies won overall. The models converged after about 900 training episodes, with an average of 27 minutes of compute time.
