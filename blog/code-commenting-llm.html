Fine-tuning T5 to comment Python code

Source on GitHub

github.com/DataChart/CodeCommentingLLM

This was a team project with Joshua Aguayo, Parker Pratt and Sam Thach: build a natural language processing tool, take it from proposal to working prototype, and present it at the end of the term.

Picking the project

We pitched six ideas: image-to-text translation, audio-to-text translation, text-to-text translation, an auto "essay" typer, automatic report documentation, and a code commenter. The translation ideas fell through because none of us spoke another language fluently and good tools already exist. The essay typer raised plagiarism concerns. Report documentation wasn't really an NLP problem.

The code commenter won. It was useful to us as developers, non-proprietary code was easy to find online, and it was an NLP problem in disguise.

Scope changes

The original plan was to generate a comment for every line of Python using Microsoft's CodeBERT. Partway through, we switched to T5 (building on a CodeT5 fine-tuning notebook for docstrings) and narrowed the scope to function definitions: the app reads a file, finds each function, and writes a docstring above it. We fine-tuned on a 10,000-example Python subset of CodeSearchNet from Hugging Face, in PyTorch, and wrapped it in a tkinter desktop app.

How well did it work?

Each of us hand-scored over 90 generated comments on a 0–2 scale (0 bad, 1 neutral, 2 good). The team average was 1.43, and my own ratings averaged 1.56. It works best on large volumes of undocumented functions, but it only handles function definitions, and the code has to start out uncommented.

Lessons learned

  • It was a translation problem the whole time: code in, English out.
  • A lot of this already exists online, so research early.
  • Scope creep is real, and so is scope change.
  • Shared lab hardware cost us a lot of time; we'd skip it next time.

We also estimated what the project would cost as a real engagement: about $6,750 in labor at $50 an hour and $10,300 in equipment, $16,750 in total.
